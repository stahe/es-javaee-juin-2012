## Resumen

Esta guía tutorial (junio de 2012) ofrece una introducción práctica a **Java EE** a través del desarrollo de una aplicación **de tres capas**:

* Resumen
* Lógica de negocio
* Acceso a datos

El documento se basa en Java EE 5 y 6 y utiliza **proyectos Maven**.

## Tecnologías tratadas

### Aplicación web

* JSF (Java Server Faces)
* EJB3 o Spring (capa de negocio)
* JPA (Hibernate / EclipseLink)

### Aplicación cliente/servidor

* Swing (cliente gráfico, compatibilidad con Spring)
* EJB3 o servicios web (servidor)

## Objetivos de aprendizaje

* Comprender la arquitectura de una aplicación empresarial Java
* Comparar EJB3 y Spring
* Implementar JPA para la persistencia
* Crear una aplicación completa con NetBeans

El documento proporciona plantillas de soluciones y deja en manos del alumno completar ciertas secciones.

## Requisitos previos

* Conocimientos del lenguaje Java
* IDE NetBeans (se recomienda aproximadamente 1 GB de RAM)

## Lecturas recomendadas

* Java 5 Persistence in Practice (JPA)
* Introducción al lenguaje Java
* Introducción a JSF / PrimeFaces
