    Este documento se basa en un documento anterior redactado en 2010 y titulado «Introducción a Java EE con NetBeans 6.8 y el servidor GlassFish v3». Esta versión incluye principalmente los siguientes cambios:

    • la sección sobre JSF (Java Server Faces) se trata en un documento independiente: «Introducción a Java Server Faces, PrimeFaces y PrimeFaces Mobile», disponible en [https://stahe.github.io/es-jsf2-pf-pfm-juin-2012/]. Utiliza características de la versión 2 de JSF,
    • los proyectos son proyectos Maven.

    Java EE son las siglas de Java Enterprise Edition. J2EE (Java 2 Enterprise Edition) era el término anterior. J2EE hace referencia a las tecnologías Java utilizadas para crear aplicaciones empresariales con JDK 1.4 o versiones anteriores. Dado que el JDK 1.5 introdujo numerosas características nuevas en el lenguaje Java, Sun introdujo nuevas tecnologías basadas en este lenguaje mejorado para subsanar las deficiencias de esas mismas tecnologías dentro de J2EE. El término Java EE 5 se utilizó entonces para referirse al conjunto de tecnologías que funcionan conjuntamente para crear una aplicación empresarial utilizando la plataforma Java. En el momento de la actualización de este documento, la última versión de Java EE es Java EE 6.

    Libros de Antonio Goncalves:

    • Java EE 5, publicado por Eyrolles
    • Introducción a la plataforma Java EE 6 con Glassfish 3, publicado por Apress

    son excelentes libros para descubrir las tecnologías de Java EE 5 y Java EE 6. Todas las tecnologías importantes de Java EE se repasan en el contexto de casos prácticos reales. El autor tiene una página web [http://www.antoniogoncalves.org] que invitamos a los lectores a visitar.

    Este documento explora algunas de las tecnologías de Java EE 5. Creamos una aplicación básica de tres capas [presentación, lógica de negocio, acceso a datos] disponible en varias versiones:

    Una aplicación web que utiliza las siguientes tecnologías:

    • Java Server Faces: para la capa web
    • EJB3 o Spring: para la capa de negocio
    • EJB3 o Spring, JPA/Hibernate, JPA/EclipseLink: para crear diferentes capas de acceso a datos

    Una aplicación cliente/servidor que utiliza las siguientes tecnologías:

    • Swing: para la capa GUI del cliente con soporte de Spring
    • EJB3 o servicio web: para la capa de servidor

    En este documento no se tratan determinadas tecnologías de Java EE, como los MDB (Message Driven Beans) o los EJB3 con estado. Para obtener más información al respecto, consulte los libros de Antonio Goncalves.

    Existen otras tecnologías de código abierto disponibles para crear aplicaciones de tres capas. Una combinación muy popular es Spring (http://www.springframework.org/) / Hibernate (http://www.hibernate.org/). Para que el lector pueda comparar las tecnologías EJB3 y Spring, la aplicación anterior cuenta con versiones en las que Spring sustituye a EJB3.

    Este documento es un tutorial (TD) utilizado en el quinto curso de la escuela de ingeniería ISTIA de la Universidad de Angers [http://www.istia.univ-angers.fr]. Este tutorial describe la aplicación que se va a construir, las tecnologías Java que se van a utilizar y dónde encontrar información. La solución propuesta suele estar muy estructurada. El trabajo plantea preguntas sin proporcionar las respuestas. Depende del estudiante encontrarlas.

    El proceso de aprendizaje de Java EE aquí descrito requiere una inversión de tiempo estimada de entre 50 y 100 horas. El documento contiene una cantidad significativa de código, lo que permite copiar y pegar. Además, todos los proyectos de NetBeans se describen en detalle. En general, el documento proporciona los marcos para las soluciones, y se pide a los estudiantes que completen ciertos detalles. El documento puede resultar útil incluso para alguien que no pueda o no quiera dedicar tanto tiempo. Uno puede centrarse únicamente en las arquitecturas descritas y saltarse la sección de código que es objeto de las preguntas.

    Para desarrollar y ejecutar la aplicación, utilizamos el IDE de NetBeans. NetBeans es una aplicación que consume bastantes recursos: se recomienda disponer de 1 GB de RAM para trabajar con comodidad. Se puede descargar desde la URL [http://www.netbeans.org/].
